Week 3: Docker

Run Nginx Container

docker run -d -p 80:80 --name my-nginx nginx

Sample Dockerfile

FROM alpine
RUN apk add --no-cache python3
COPY app.py /app/
CMD ["python3", "/app/app.py"]

Week 4: Kubernetes

Deployment (deploy.yml)

apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deploy
spec:
  replicas: 2
  template:
    spec:
      containers:
      - name: nginx
        image: nginx:alpine

Week 5: Terraform

Create GCP VM (main.tf)

resource "google_compute_instance" "web" {
  name         = "my-vm"
  machine_type = "n1-standard-1"
  zone         = "us-central1-a"
  boot_disk { initialize_params { image = "debian-cloud/debian-11" } }
}

❓ Common Questions

Q: Docker vs VM?
A: Containers share the host OS (lightweight), VMs emulate full OS.

Q: Why Kubernetes?
A: To manage 100s of containers across servers (auto-scaling, healing).
