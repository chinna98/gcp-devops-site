What is DevOps?

  • Waterfall vs Agile methodologies

  • Importance of Linux in DevOps

Mastering Shell/Bash Scripting

  • Basics of Shell/Bash scripting.

  • Applying scripting concepts to automate tasks in the real-time project, ensuring hands-on experience.

Shell Scripting Essentials

Mastering Ansible

  • Learn YAML, Playbooks, and Roles.

  • Apply these concepts through the real-time project for configuration management and automation.

Ansible Configuration Management

Week 7-8

Infrastructure as Code with Terraform

  • Introduction to Terraform and its syntax.

  • Writing Terraform configurations.

  • Managing infrastructure with Terraform integrated into the real-time project.

Infrastructure as Code with Terraform

Week 9-10

Jenkins CICD Mastery

  • Comprehensive coverage of Jenkins CICD pipeline.

  • Integration with Terraform, Ansible, and Shell scripting for continuous integration and continuous deployment.

Containerization with Docker and Kubernetes

  • Learn the basics and advanced concepts of Docker  and Kubernetes.

Monitoring and Management

  • Python basics and scripting

  • Complete the course with monitoring tools like ELK (Elasticsearch, Logstash, Kibana), Prometheus, and Grafana.

Is this course free?

The course is not free; however, you can attend a demo and the first week’s sessions at no cost. This allows you to decide whether to continue with the course.

Is there any placement assurance?

Yes, we have exclusive job portal also we provide placement assistance, resume building, interview preparation, mock interviews, and internal job referrals.

I have very basic knowledge about DevOps. Will I be able to cope with this course?

Absolutely! We start from the basics of Linux and cover all tools from beginner to advanced levels. The only prerequisite is basic computer knowledge.

How will the classes be conducted?

All sessions will be held virtually. We do not offer any offline sessions.

What if I miss a live session? How will I catch up?

No worries! You will receive recordings of all sessions of this batch with lifetime access, allowing you to review the material anytime and anywhere.

How does QA support work?

We offer a daily 6-hour QA window (6 days a week) for query resolution through Zoom session with experts, also have Slack Community for doubts clarification and network building

Are there any real-time projects we will work on during the course?

Yes, we cover two complete real-time projects during the course. The course is project-oriented, ensuring you gain practical, hands-on experience working on real projects.

Do we need to purchase GCP accounts separately for practice?

Yes, you will need to create an GCP free tier account for practice purposes. Don’t worry; we will guide you on how to use GCP and share best practices to avoid accidental costs.

Is only a weekend class available?

No, this course is conducted on weekdays only.
